# Special-form availability research

Reviewed **2026-09-22** against Bulbapedia species `Form_data` and `Game_locations` sections
(including the existing local HTML cache), with current item/distribution pages checked where
needed. Apply the [canonical field definitions](../pokemon-availability.md), not the everyday
meaning of "event Pokémon". O = `obtainableIn`, T = `transferOnlyIn`, E = `eventOnlyIn`.

This is an implementation decision reference. It does not itself certify that every proposed storage
correction has been applied. GO must use its own exact-form release evidence; none of these
main-game inheritance decisions authorizes GO inheritance. Champions eligibility is also outside
these main-game rules and never establishes O.

unavailable species/game combinations, and unsupported mechanics remain excluded.

## Fusions need both components

fused result itself cannot be traded. T in the table below means an imported component is needed,
not that the already-fused result can cross a game boundary. All listed persistent fusions can be
boxed locally, but must be separated before Bank/HOME transfer.

unresolved in the GO coverage report; these releases do not establish their availability.

## Limits

- Supported game lists describe the current reviewed games, not a promise that future titles will
  preserve the mechanic. LZA specifically supports Primals, both newer Zygarde forms and Hoopa
  Unbound; it does not thereby support every legendary transformation.
- Storage corrections require exact deposit/withdrawal behavior. Preserve unverified saved storage
  values outside explicit exclusions instead of overwriting the entire array from a base.
- This audit does not revise shiny locks or global shiny-release fields. Shared appearance,
  evolution, fusion and form-change mechanics are not sufficient evidence for those fields.
